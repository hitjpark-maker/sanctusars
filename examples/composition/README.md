# 구도 선택 예시

사용자가 좋다고 다시 고른 여섯 그림이다. 매일 같은 여섯 구도를 채우는 목록이 아니다. 복음의 인용문 또는 축일의 대상이 먼저이고, 그 관계를 가장 잘 드러내는 거리와 시점을 고른다. 한 장씩 보아도 완결되고 여러 장을 함께 올려도 반복이 적은 세 후보를 만든다.

| 그림 | 참고할 선택 | 적합한 경우 |
| :--- | :--- | :--- |
| [높은 시점의 기다림](vigil-high-angle.png) | 작은 인물과 넓은 공간, 위에서 보는 거리 | 기다림과 보이지 않는 부름, 하느님의 시선을 암시할 때 |
| [성탄의 위쪽 시점](nativity-overhead.png) | 아기와 두 손을 중심에 두고 주변 사건 생략 | 한 생명에게 시선을 모을 때 |
| [성탄의 가까운 시점](nativity-close.png) | 얼굴과 시선, 감싸는 손만 남김 | 인물의 존재와 표정이 핵심일 때 |
| [두 인물의 넓은 만남](encounter-wide.png) | 관계와 거리를 읽을 정도의 넓이 | 두 사람의 위치가 말씀 이해에 필요할 때 |
| [정면의 기다림](vigil-frontal.png) | 시선과 불꽃을 중심축으로 연결 | 인물의 결심이나 깨어 있음이 핵심일 때 |
| [등불의 세부](vigil-detail.png) | 손과 작은 불꽃만으로 의미 유지 | 한 동작이나 상징만으로 인용문이 읽힐 때 |

물에 비친 상, 사람들 사이로 보이는 인물, 문틈의 일부처럼 간접적인 시점도 본문이 그것을 요구할 때만 고려한다. 효과 자체가 말씀의 초점보다 앞서면 쓰지 않는다. 축일은 성인이 먼저 읽혀야 하므로 정면 또는 가까운 인물 중심 구도를 적극 고려한다. 상황의 관계가 중요하면 와이드를 충분히 사용하며 인물을 억지로 작게 만들거나 장면을 의미 없는 추상으로 줄이지 않는다.

이 그림들은 **장면 선택을 위한 검토 자료**다. `prepare`가 내장 이미지 생성 도구에 전달하는 참조는 계속 `brand/references/v5/`의 후보별 두 장이다. 여기의 아기, 여인, 예수님, 손, 옷, 색면 경계를 새 그림에 복제하지 않는다. 이 여섯 장의 스타일이나 구도가 새로 생성할 모든 그림의 품질을 보장하지도 않는다.
