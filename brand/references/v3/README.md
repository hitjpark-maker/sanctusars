# 현재 공간 참조와 생성 지시 v3

공간 참조는 사용자가 방향을 채택한 painted-light-02의 두 원본이다. 완성도가 부족하다고 평가된 10월 2일 후보를 확정 화풍으로 승격하지 않는다. modern-space.png는 넓은 색면과 생략된 공간, modern-close.png는 인물 사이의 시선·간격을 보여 준다. 두 장을 실제 도구 입력으로 전달한다.

참조의 차가운 파랑은 복제하지 않는다. 현재 generation.json은 중성에 가까운 은은한 온기, 아이보리·돌색·절제된 장밋빛과 깊은 자주를 지정한다. 얼굴·손은 온전히 읽히면서 같은 물감으로 그려야 한다. 세밀한 피부와 반복 표면 무늬는 따라하지 않는다.

모든 수정 요청은 새로운 그림으로 생성한다. 기존 후보를 편집 대상으로 넣지 않는다. 함께 보존한 prompt.txt는 참조 원본의 제작 이력이며 현재 프롬프트를 대신하지 않는다. 이번 시안은 아직 최종 승인되지 않았고 새 생성의 미적 품질이나 계정 간 동일 결과를 보장하지 않는다.
