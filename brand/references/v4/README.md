# SanctusArs 확정 스타일 v4

사용자 확정: “새 버전 이미지들 좋다. 이대로 시스템 업데이트 해서 깃 푸쉬하기 바람.”

2026년 10월 2일 마지막 신규 생성 A/B/C 원본을 변경 없이 보존한다. 중성에 가까운 은은한 온기, 아이보리·돌색과 절제된 자주, 불완전한 공간과 추상 색면, 읽히는 시선·몸짓의 관계가 기준이다. 차가운 파랑이나 뜨거운 주황으로 다시 해석하지 않는다. 얼굴을 사진처럼 더 정밀하게 하거나 질감을 더 거칠게 과장하지 않는다.

wide.png는 와이드 구성과 색면, close.png는 가까운 눈맞춤과 인물 표현, viewpoint.png는 관찰자의 위치와 가려진 공간의 기준이다. 각 호출에는 두 장을 전달한다. A는 wide+close, B는 close+wide, C는 viewpoint+wide다. 모든 후보에서 최신 원본을 실제로 읽고 입력하며 옛 참조로 대체하지 않는다.

해당 날짜의 인물·행동·구도는 새로 설계한다. 어린이와 의상·얼굴·모임 장면을 다른 복음에 복제하지 않는다. 모든 수정 요청도 새 생성이며 참조를 편집 대상으로 쓰지 않는다. prompt.txt는 원본 제작 이력이고 현재 생성 지시는 ../../generation.json이다.

이 확정은 스타일과 배포의 승인이다. 개별 A/B/C 선택·카드 최종 승인·실제 게시와는 별개다. v1부터 v3까지는 이력으로 보존한다.
