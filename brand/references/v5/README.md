# SanctusArs 현재 스타일 v5

2026년 10월 6일 제작 후 사용자가 글과 함께 보는 간결한 현대미술 방향을 기본으로 정했다. 이 승인은 화풍 방향에 관한 것이며, 해당 날짜의 최종 게시 승인이나 개별 후보 선택 기록은 아니다. `examples/2026-10-06/`에 당시의 글과 세 시안을 보존한다.

`minimal.png`가 최우선 기준이다. 작은 경청의 단서와 큰 두 색면만으로 인용문의 관계를 남긴다. `close.png`는 그보다 표정이 읽히는 간결한 시안이다. `wide.png`와 `viewpoint.png`는 각각 넓은 구도와 관찰자 위치의 선택을 참고하되, 거기서 보이는 장면 설명의 양은 더 줄인다. 이 그림들의 마리아, 예수님, 손, 옷, 길과 색면 경계를 새 날짜에 복제하지 않는다.

이 네 장에는 측면 인물이 많다. 실제 생성 입력으로 들어가므로 금지 문구만으로 닮은 얼굴이나 구도를 완전히 막을 수 없다. 본문과 인용에서 새 장면의 시점·인물·동작을 먼저 정하고, 참조는 색 관계·매끈한 표면·생략 정도에만 쓴다. 생성 후 참조 및 사용 가능한 최근 승인·게시 그림과 비교해 얼굴형·카메라 축·인물 배치가 반복되면 장면을 새로 설계한다. 그래도 반복이 계속되면 인물이 없는 스타일 전용 참조로 교체하는 별도 시안을 사용자와 검토한다.

복음 그림은 전체 복음을 장면의 맥락으로, 따옴표 안 말씀을 초점으로 삼는다. 축일 그림은 기념하는 성인을 초점으로 삼고 복음은 보조 맥락으로 둔다. 세 후보 모두 불필요한 인물과 소품을 덜어내며 B는 의미가 유지되는 최대치까지 단순화한다. 참조는 색면의 비율과 생략의 정도를 알려 줄 뿐, 모든 그림을 같은 청색 밤이나 같은 구도로 만드는 틀이 아니다. 파랑은 핵심 색이지만 낮의 빛과 함께 써도 된다. 자주색은 제한적으로 쓰고 미세한 질감은 일부 경계에만 남긴다.

후보의 거리를 달리하는 것만으로 충분한 차이를 만들 수 없을 때는 카메라 높이와 방향, 화면 중심축을 바꾼다. 매일 위·정면·와이드를 정해진 순서로 만들지 않는다. 본문이 인물의 표정이나 결단을 요구하면 가까운 정면을, 관계의 맥락을 요구하면 넓은 시야를 쓴다. 위쪽 시점은 하느님의 시선을 암시할 수 있고, 반영이나 가림은 말씀에 실제 의미를 더할 때만 쓴다. 사례는 `../../../examples/composition/README.md`에 있다. 한 장씩 보아도 완결되고 여러 장을 함께 게시해도 관점이 반복되지 않게 한다.

거룩한 인물이 실제로 등장하면 `close.png`의 옷자락과 곁의 공기에 퍼지는 밝기, `minimal.png`의 부드러운 빛 경계처럼 국소적인 빛을 한 곳에 둔다. 빛의 위치나 모양을 복제하지 않고 새 장면의 인물과 말씀에 맞춘다. 단단한 원형 후광이나 전면 발광으로 바꾸지 않는다.

각 후보의 실제 입력 참조는 `generation.json`에 고정되어 있고 `manifest.json`이 파일 해시를 검증한다. 복음 조합은 A: wide와 minimal, B: minimal과 close, C: viewpoint와 minimal이다. 축일 조합은 A: close와 minimal, B: minimal과 close, C: viewpoint와 close다. 축일에는 `wide.png`를 입력하지 않고 기념하는 성인의 인물성을 우선한다. 그림은 매번 새로 생성한다.

축일 C는 가까운 인물화로 제한하지 않는다. 인물 중심을 유지하는 넓은 전신 구도 또는 A와 실질적으로 다른 관점·자세를 택한다. B는 손·표정·상징의 의미 있는 확대이며 임의의 반쪽 얼굴을 최소안으로 삼지 않는다. 생성 전후 세 쌍을 비교하는 기준은 `../../style.md`의 함께 게시할 수 있는 세 옵션을 따른다.
