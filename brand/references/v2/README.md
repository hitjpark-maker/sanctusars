# SanctusArs 이전 스타일 v2

사용자 요청: “이 방향이 더 낫다. 이제 이 스타일대로 10월2일 복음 포스팅을 만들어주기 바람.”

두 시안의 넓은 색면, 극적인 명암, 생략된 공간, 조용한 표면과 인물 붓질의 대비를 적용한다. 후속 요청에 따라 따뜻한 톤이 기본이며 이미지에 남아 있는 차가운 청회색은 복제하지 않는다. 크림·살구·장밋빛과 깊은 자주 계열을 주제에 맞게 사용한다. 세피아·황금빛 고화로 돌아가지 않는다.

두 실제 이미지 모두 생성 입력으로 전달한다. modern-space.png는 넓은 공간, modern-close.png는 인물 관계와 간격의 참조다. 후보별 순서와 현재 색감 지시는 generation.json에서 지정한다. 인물·손·문을 그대로 복제하지 않는다. 눈과 손은 온전히 그리며 사진 같은 피부 세부와 반복 비늘 요철은 억제한다. 함께 보존한 원래 프롬프트는 출처 이력이며 현재 색감 지시가 아니다.

이전 v1은 이력으로 보존한다. 새로운 포스팅의 이미지 선택과 최종 승인은 별도다. 10월 2일의 새 따뜻한 후보는 아직 선택되지 않았으므로 이 참조를 자동 교체하지 않는다.

현재 제작 기준은 ../v3/README.md다. 이 폴더의 차가운 원본은 생성 입력으로 사용하지 않는다.
