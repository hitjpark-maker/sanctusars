# SanctusArs 확정 스타일 v1

사용자 확정 문구: “좋다 이 방향으로 픽스한다.”

최신 복음·축일 여섯 장을 보존한 화풍 참조 세트다. 개별 시안 선택 또는 최종 게시 승인은 아니다. 원본 제작 기록은 `output/`에 보존하고 이 세트는 Git 배포 대상 경로에 둔다. 공개 게시와 라이선스 부여는 별개다.

새 제작에서는 `../../style.md`와 이 이미지들을 함께 보고 구도·색·표면·표정의 기준을 이해한다. 날짜별 검증된 복음으로 새로운 장면을 만든다. 이 세트의 인물·무화과나무·대천사·구도를 매일 복제하지 않는다.

함께 둔 프롬프트는 마지막 수정 단계의 실제 기록이다. 이전 이미지에 대한 편집 지시이므로 새 그림의 완성형 단독 프롬프트로 오해하지 않는다. 새 제작은 이 폴더의 이미지를 화풍 참조로 지정하고 해당 날짜의 내용·장면·불변 조건을 별도로 작성한다. 파일 해시와 출처는 `manifest.json`에서 확인한다.

같은 프롬프트와 참조를 사용해도 결과와 품질은 동일하다고 보장하지 않는다. 사용자 피드백, 인체와 표정 검수, 필요한 수정 과정을 유지한다.
