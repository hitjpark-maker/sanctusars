# SanctusArs 글 형식

기본은 짧은 포스팅이다. 채널 이름 때문에 블로그 글을 자동으로 늘리지 않는다. 현재 복음 예시 `examples/2026-10-06/post.txt`는 공백·줄바꿈 포함 240자다. 이 길이와 문단의 호흡을 출발점으로 삼는다. 길이를 맞추기 위한 군더더기나 필요한 맥락의 삭제는 하지 않는다.

## 복음

아래 순서로 쓴다. 대괄호는 작성 지시이며 게시문에 출력하지 않는다.

```
“[검증한 짧은 말씀]”
[해당 인용의 가톨릭 장절]

[말씀의 핵심 관계를 짚는 짧은 문단. 줄거리 전체 요약 금지.]

[구체적인 생활 장면 한 가지로 이어지는 짧은 묵상.]

[짧은 기도 한 문장.]

[날짜 한 번]
```

기본 목표는 전체 약 200자에서 300자다. prepare는 기본 복음 본문이 공백·줄바꿈 포함 300자를 넘으면 차단한다. 짧은 글을 억지로 늘리지는 않는다. 초과하면 Codex가 중복 설명부터 덜어내 다시 작성한다. 사용자가 먼저 긴 글을 요청한 경우에만 실제 요청 문구로 확장 경로를 사용한다. 해설 문단 여러 개, 추상적인 정의, 생활 실천 여러 가지, 독자를 훈계하는 결론을 쌓지 않는다. ‘본문 가운데 5절의 말씀입니다’ 같은 설명은 장절을 한 번 정확히 적으면 필요 없다. 전체 복음 범위와 검증 출처는 제작 기록에 보존한다. 게시문에 필요한 경우 인용 출처와 한 곳에 모아 표기한다. 그림의 초점이 될 짧은 인용을 먼저 정한 뒤 그 말씀의 관계만 짧게 풀어 주고, 생활 장면 한 가지로 연결한다. 그림이 재현할 필요가 없는 맥락은 글이 전한다.

Threads와 네이버 블로그 본문은 **기본적으로 같은 짧은 본문**을 사용한다. 블로그 제목은 별도 필드나 화면 라벨로 제안할 수 있으나 본문을 해설문으로 확장하지 않는다. 긴 블로그 묵상은 사용자가 요청할 때만 별도로 쓴다.

## 축일

검증한 월·일과 공동 축일명 → 대상 전체에 대한 축하 한 번 → 함께 기념하는 대상과 핵심 의미 → 짧은 생활 묵상 → 기도 순서다. 기본 목표는 약 250자에서 350자이며 prepare의 기본 상한은 350자다. 필수 설명은 유지하고 중복 묵상을 줄인다. 대천사를 인간 성인의 생애처럼 쓰지 않는다.

세례명 축하는 독자에게 직접 건네는 자연스러운 말로 쓴다. 남성 성인은 “안셀모 형제님들, 축일 축하드립니다.”처럼, 여성 성인은 이름 뒤의 호칭만 바꾸어 “○○ 자매님들, 축일 축하드립니다.”처럼 쓴다. “안셀모라는 세례명을 지닌 분들께 축하를 전합니다.”처럼 대상을 설명하는 문어체는 피한다.

## 문체와 제시

가톨릭 성경·용어만 사용한다. 차분한 문장으로 쓴다. 해시태그, 강조용 느낌표, 엠데시·하이픈, 끝의 브랜드 서명, 날짜·장절 꼬리말 반복을 넣지 않는다. 질문은 자연스러운 경우에만 쓴다. ‘마음 하나’, ‘마음이 쉬어 가는 곳’ 같은 감성 질문이나 억지 댓글 유도는 넣지 않는다. 매번 ‘오늘은 … 해 보려 합니다’를 복사하지 않는다.

최종 응답은 **복음 포스팅의 실제 본문 → 그림 옵션 A/B/C** 순서로 보여 준다. 본문이 같으면 ‘Threads·네이버 블로그 공통 본문’으로 한 번 제시하고 두 저장 파일에는 각각 기록한다. 축일 요청도 있으면 그 다음에 **축일 본문 → 축일 그림 A/B/C**를 독립적으로 묶는다. 내부 검증 메모를 게시용 본문에 섞지 않는다.

제시 전 짧은 기준 예시와 나란히 읽어 길이·문단·구체성을 비교하고, 실제 문자 수와 길어진 이유가 있으면 브리프에 기록한다. 이 숫자는 품질 점수나 자동 승인 기준이 아니다.

`reference`에는 검증된 전체 복음 범위를 보존한다. `display_reference`에는 게시문에 한 번 표시할 인용 절을 적고 evidence의 `quotation_reference`에 실제 확인한 같은 절을 기록한다. 전체 범위를 표시할 때는 장절을 풀어 쓴다. 둘을 하단에 다시 반복하지 않는다. prepare는 두 채널의 공통 본문, 길이, 금지 표현, 날짜·인용·출처 표기를 확인한다. 검사는 문체의 자연스러움을 대신하지 않는다.
