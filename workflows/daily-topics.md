# 매일 포스팅 주제 준비

매일 **한국 시간(Asia/Seoul) 오전 4시 30분**에 그날의 복음과 특별 주제를 조사한다. 사용자가 번호나 주제명으로 응답한 뒤에만 글과 이미지 A/B/C 제작을 시작한다. 실제 게시를 자동 실행하는 기능은 아니다.

## 처음 내려받은 사용자의 예약 설정

이 저장소를 Codex에서 열고 다음과 같이 요청한다.

> 이 저장소의 workflows/daily-topics.md에 따라 매일 한국 시간 오전 4시 30분에 이 대화에서 포스팅 주제를 준비하도록 예약해줘.

Codex는 앱의 예약 도구로 현재 대화에 연결된 예약을 생성한다. 같은 목적의 기존 예약이 있으면 갱신하고 중복 생성하지 않는다. 아래 실행 지침을 읽도록 예약 프롬프트에 저장소 위치와 이 문서 경로를 넣는다. 시간대와 활성 상태를 확인한다. 예약 도구가 없으면 설정 완료라고 말하지 않는다.

**git pull은 제작 지침과 도구를 가져오며 앱의 예약 자체를 설치하지 않는다.** 각 사용자는 자신의 앱에서 한 번 예약을 설정해야 한다. 개인 예약 ID, 대화 ID, 계정 설정은 Git에 넣지 않는다. 로컬 파일을 사용하는 예약은 컴퓨터와 앱이 실행 중이고 저장소에 접근 가능해야 한다. 실제 무인 실행과 사용량은 각 환경에서 확인한다.

## 예약 실행 지침

1. 최신 AGENTS.md, README.md, brand/style.md, brand/editorial.md를 읽는다. 한국 날짜를 YYYY-MM-DD로 확정한다. 늦게 실행되었다면 실제 실행 시각을 기록하고 예정 시각에 실행했다고 주장하지 않는다.
2. 주교회의 해당 날짜 매일미사의 날짜·전례일·복음 구역·장절을 직접 읽고 전례력 및 굿뉴스의 날짜별 자료와 대조한다. 복음의 핵심 주제를 짧게 정한다. 검색 요약이나 전년도 자료로 대체하지 않는다. 재전재 자료를 독립 원문 검증으로 과장하지 않는다.
3. 주요 전례일과 대축일·축일·기념일, 잘 알려진 성인의 기념 날짜를 확인한다. 성인의 날짜·생애·핵심 의미는 공식 가톨릭 자료로 확인한다. 한국 전례력, 지역·수도회 고유 거행, 성인 기념 날짜를 구분한다. 유명하다는 이유로 전례 등급을 높이지 않는다. 관련성 높은 주제만 추천하고 특별 주제가 없으면 복음만 제시한다.
4. output/YYYY-MM-DD/daily-topics/에 조사 기록을 새 버전으로 보존한다. 실제 조회 시각, 출처 URL, 직접 확인한 내용, 확인 범위·접근 실패, 전례 등급, 복음 선택지, 추천 이유를 적는다. 각 번호와 절대 날짜·제작 종류·대상·미사 구분·장절을 연결한다. 기존 제작 건이나 승인을 덮어쓰지 않는다. 같은 날짜의 실제 준비 알림이 이미 있고 변경이 없으면 중복 알리지 않는다.
5. **기본 UI는 짧은 번호 목록과 텍스트 응답이다.** 날짜, 전례일, 각 주제 제목과 설명 한 문장, 필요한 출처 링크를 제시한다. 끝에는 실제 주제에 맞춰 “1, 2, 둘 다, 또는 건너뛰기로 답해주세요.”처럼 안내한다. 한 주제면 “1 또는 건너뛰기로 답해주세요.”로 쓴다. 번호·제목·자연어 선택을 모두 받는다.
6. 이 환경에서는 codex-followup과 request_user_input_async 모두 사용자에게 선택 UI가 보이지 않은 사례가 있다. **선택창을 기본 경로로 사용하지 않는다.** 도구가 accepted를 반환해도 사용자에게 UI가 보인다는 증거는 아니다. 보이지 않는 버튼을 누르라고 하거나 선택창을 띄웠다고 말하지 않는다. 별도 화면 개발 없이 텍스트 선택만으로 전체 흐름이 가능해야 한다.
7. 미해결 복음 선택이 있으면 미사 구분·장절이 명확한 별도 번호로 제시한다. 주제 자체가 미확인이면 제작 가능한 것으로 제시하지 않는다. 주제는 확인했으나 전체 본문의 추가 교차 검증이 남았다면 한계를 기록하고 제작 전 보완한다. 불일치가 해결되지 않으면 제작을 보류한다.
8. 사용자가 응답하면 기록에 연결된 절대 날짜와 대상을 사용한다. 응답일의 ‘오늘’로 날짜를 바꾸지 않는다. 여러 날짜의 안내 중 어느 것을 가리키는지 불명확하면 날짜만 확인한다. 선택한 제작 건의 status를 확인하고 기존 작업을 재개하거나 독립 생성한다. 최신 AGENTS.md에 따라 검증·짧은 본문·서로 다른 이미지 A/B/C·시각 검수를 수행한다. 특별 성인 포스팅에 불필요한 복음 선택을 다시 요구하지 않는다.
9. 사용자 응답 전에는 이미지나 포스팅 본문을 생성하지 않는다. 주제 선택은 제작 시작 지시이며 이미지 선택·최종 승인과 별개다. 자동 게시, 예약 게시, 자동 Git push, 추가 결제는 하지 않는다.

## 수동 테스트

“2026년 10월 12일 새벽 4시 30분이라고 가정하고 준비해줘. 테스트야.”처럼 요청할 수 있다. 실제 출처를 조회하되 mode를 manual_schedule_test로, 가정한 시각과 실제 조회 시각을 별도로 기록한다. 테스트는 실제 예약 실행·발송 완료나 제작 승인으로 세지 않는다. 이후 실제 예약 실행의 중복 방지에도 포함하지 않는다.

현재 확인 범위: 2026년 10월 10일과 12일의 주제 조사와 안내를 수동 테스트했다. 선택 UI는 사용자 화면에 나타나지 않았고 번호·주제명 응답 방식으로 전환했다. 이 테스트는 새벽 무인 실행이나 다른 사용자 환경의 예약 성공을 검증한 것이 아니다.
