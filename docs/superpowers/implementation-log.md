- Task 4: 자산 내장 HTML, 작품형·말씀카드형 1080×1350 캔버스, 채널별 글, 출처와 해시 기반 승인·내보내기 구현. 합성 PNG로 등록→승인→내보내기 및 승인 후 변조 차단을 단위 테스트했다.
- Task 5: README, 제작 지침, 고정 브랜드 가이드와 B 기준 그림을 저장했다. 2026-09-28 공식 매일미사와 굿뉴스를 실제 대조하고 내장 도구로 A/B/C를 생성했다. 사용자의 “B — 깊은 명암과 신비로움” 선택을 실제 제작 건에 기록했다. 이는 최종 게시물 승인이 아니다.
- 실제 자료 확인: 9월 28일 루카 9,46-50, 12월 25일 밤·새벽·낮 미사 선택 구분, 8월 15일 날짜별 페이지를 조회했다. 굿뉴스는 주교회의 자료를 재전재하므로 독립 원문 증거로 표현하지 않았다.
- 한 차례 최종 리뷰에서 후보 교체 시 과거 프롬프트·해시 누락, 승인 무효화 시 승인 파일 내역 누락, HTML 출처 링크 누락을 발견했다. 회귀 검사 실패를 확인한 뒤 전체 이력을 보존하고 링크를 표시하도록 수정했다. occasions=null도 예외 대신 검증 오류를 반환한다. 수정 후 11개 테스트 통과.
- 브라우저 합성 조판 테스트: AppleMyungjo.ttf는 FontFace 로딩 오류를 표시했다. 로컬 Arial Unicode.ttf로 바꾼 테스트에서 렌더링 완료 상태와 출처 링크 3개를 확인했다. 테스트 글꼴은 재배포하지 않는다.
- 브라우저 PNG 다운로드 이벤트는 두 차례 시간 초과했다. 다운로드 내부 페이지 확인은 브라우저 URL 정책에 의해 차단되어 우회하지 않았다. 실제 다운로드 파일의 시각 검사·등록까지 완료했다고 주장하지 않는다. 실제 공식 로고·한글 글꼴로 제작할 때 이 검증을 마쳐야 한다.
- 남은 제작 입력: 공식 로고·사용 가능한 한글 글꼴, 실제 최종 카드 및 게시문 승인. GitHub 원격과 공개 라이선스도 미정이다. 자동 게시 기능은 포함하지 않았다.
- 통합 판단: 새 저장소여서 병합할 기반 브랜치가 없다. 로컬 구현을 보존하고 원격 게시·병합은 수행하지 않는다.


## 2026-09-29 공유용 정리

기본 제작량은 복음 한 건과 그림 세 장이다. 특별 포스팅은 요청받을 때만 추가한다. 확정 참조 이미지 여섯 장, 실제 마지막 편집 프롬프트, 채널별 글 예시를 저장소에 포함했다. 화풍 확정과 개별 게시물 승인을 구별한다. 코드와 직접 작성한 문서는 MIT로 배포한다.

Python 3.12에서 단위 테스트 12개 통과. 참조 이미지 여섯 장의 SHA-256과 배포 문서의 상대 링크를 확인했다. 실제 제작 기록 output/는 배포하지 않는다. 별도 Plus 계정의 새 세션에서 이미지 생성 품질 재현, 월 90장 사용량, 실제 카드 PNG 다운로드의 종단 간 검증은 완료로 주장하지 않는다.


## 2026-10-01 제작 재현 실패 보고에 따른 지침 수정

이 항목의 날짜는 사용자가 제출한 제작 대상일이며 수정 실행일을 뜻하지 않는다. 기존 커밋 e7e119c의 brand/style.md:7,19,40에는 초기 B 기준이 남아 있었고 :46은 현대성을 허용 사항으로, :57은 실제 이미지 참조를 조건부로 적었다. templates/content.json은 빈 필드만 제공했고 examples/2026-09-29/README.md에는 짧은 Threads와 긴 블로그 예시가 함께 있었다. scripts/sanctusars.py의 check는 전례 자료 구조 검사이며 candidate는 파일·문맥 기록이다. 글의 문체와 회화적 품질을 판정하는 코드가 아니다.

사용자가 제출한 세 장은 균일한 표면 묘사, 남색과 황금빛, 상세한 고전적 풍경이 반복되며 최신 참조의 넓은 색면·생략·표면 강약과 차이가 있다. 원격 실행의 프롬프트, 실제 이미지 입력, 모델 설정은 확보하지 못했으므로 참조 누락이나 특정 모델을 직접 원인으로 단정하지 않는다.

현재 기준만 남기도록 스타일 문서를 재작성하고, 매 생성에 실제 참조 이미지 두 종류를 전달하는 절차와 새 장면용 완결된 프롬프트 양식을 추가했다. 글은 짧은 기준 본문을 기본으로 두 채널에 사용하도록 명시했다. 과거 긴 블로그 예시는 기본값에서 제외하되 이력은 보존했다. 생성 후 참조와의 구체적인 비교 기록을 요구한다. 이는 에이전트 실행 지침이며 코드가 도구 호출이나 미술 품질을 강제한다는 뜻은 아니다.

문서 변경 후 Python 3.12 단위 테스트 12개 통과. 이 테스트는 문체·화풍 재현을 검증하지 않는다. 새로운 이미지 생성 및 별도 계정의 재시험은 이 수정에서 수행하지 않았다. 실제 사용자의 원본 실패 이미지와 대화 기록은 공개 저장소에 복사하지 않았다.
