## 2026-09-29 생성 입력을 코드로 준비하는 경로

후속 실패 보고에서도 화풍 편차가 이어졌다. 최종 확정본은 후보별 5회부터 7회까지의 버전 등록을 거쳤고, 지침만 배포한 경로에서는 매번 실행 모델이 전체 생성 지시를 다시 작성했다. 다른 컴퓨터의 실제 도구 입력은 확인하지 못했으며 특정 계정·모델·사용자의 잘못으로 단정하지 않는다. 진단 자료 수집을 사용자에게 요구하지 않고 저장소 자체의 입력 경로를 변경했다.

이미지 생성은 계속 Codex의 내장 도구가 실행한다. 준비 명령은 Python에서 AI를 실행하는 API가 아니다. 기록 일치 검사는 실제 도구 전달 사실이나 그림의 미적 수준을 증명하지 않는다. 명백한 결함이 확인된 후보에만 `refine`으로 원본을 보존한 편집 요청을 준비하며, 기본 제작에 세 번의 추가 생성을 일괄 부과하지 않는다.

실제 생성 검증 소재는 사용자가 문제 사례로 제시한 2026-10-01 루카 10,1-12다. 주교회의와 굿뉴스의 해당 날짜 복음 구역을 다시 직접 확인했다. 기념일 대체 복음 마태 18,1-5도 존재하지만 이 검증은 사용자가 제시한 루카 본문과 동일 소재 비교이며 미사 선택·게시 승인을 기록하지 않는다. Threads·블로그 공통 글은 228자다. `output/recipe-verification/`에 실제 입력과 생성물을 보관하며 공개 Git에 사용자 실패 이미지나 제작 기록을 추가하지 않는다.
